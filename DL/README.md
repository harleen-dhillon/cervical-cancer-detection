# Deep Learning — Cervical Cell Classification

This section explores image-based cervical cell classification using the SIPaKMeD dataset.

## Experiments
- Dataset auditing and group-aware data splitting
- ResNet18 image classification
- Strong versus mild data augmentation
- Training and validation performance analysis
- SVM-based classification using deep features
- PSO-SVM experiments, where implemented
- Grad-CAM visualizations for model interpretation

## Dataset
The SIPaKMeD dataset is not included in this repository. Download it separately and configure the dataset path in the notebooks before running experiments.

## Notebooks
- `01_dataset_audit.ipynb`
- `02_augmentation_and_baseline.ipynb`

## Results
Saved visualizations include training curves, confusion matrices, augmentation comparisons, and Grad-CAM examples.

These are artifacts from previous experiments. Reproducibility requires the corresponding code, dataset, and configuration.
